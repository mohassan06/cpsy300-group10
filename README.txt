CPSY 300 Team Project — Phase 1 starter files (given code)

Copy these into your project folder (cpsy300-<team>), keeping the folders:

  lib/data.ts                    reads data/All_Diets.csv
  lib/insights.ts                the five cleaning rules and the five insights
  app/page.tsx                   the dashboard page (REPLACES the page.tsx create-next-app made)
  app/components/Charts.tsx      the three charts
  app/api/insights/route.ts      the JSON route, /api/insights

They need three packages:  npm install papaparse @types/papaparse recharts react-is@19
The brief, Part A, says exactly when and how.
